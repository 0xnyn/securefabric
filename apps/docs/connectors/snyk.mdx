### How it will stay current

Each sync reads issues updated since the last sync.

## What your customers will need

- Authorization through a Snyk App, or a service account token on Snyk Enterprise.
- Your Snyk region: US-01, US-02, EU or AU. Tokens work only in their region.

## Good to know

- Covers Snyk Open Source, Snyk Code, Snyk Container and Snyk IaC.

## Until it's available

Build against the [Sandbox](/connectors/sandbox) connector, which produces findings of every type. Every connector shares one data model, so the code you write keeps working when this connector ships.
