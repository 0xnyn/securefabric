## What SecureFabric will sync

| | |
|---|---|
| Resources | `REPOSITORY`, `BRANCH`, `IMAGE` |
| Findings | `CODE`, `DEPENDENCY`, `CONTAINER`, `SECRET`, `IAC` |

From GitLab:

- The vulnerability report, per group and project
- Projects
- Branches

### How it will stay current

Each sync reads vulnerabilities updated since the last sync.

## What your customers will need

- GitLab Ultimate. GitLab's vulnerability APIs are only available on Ultimate.
- A project, group or personal access token with the `read_api` scope, or OAuth authorization.

## Good to know

- Self-managed GitLab versions vary; supported versions will be listed here at release.

## Until it's available

Build against the [Sandbox](/connectors/sandbox) connector, which produces findings of every type. Every connector shares one data model, so the code you write keeps working when this connector ships.
