A connector is SecureFabric's support for one vendor product. Every connector maps its vendor's data into the same [findings](/concepts/findings) and [resources](/concepts/resources), so code you write for one works for all of them.

`GET /v1/connectors` returns the live catalog, with each connector's streams, permissions, options and credential fields. It needs no API key.
