From Defender GCC High:

- The same data as [Microsoft Defender Vulnerability Management](/connectors/microsoft-defender), from Microsoft's US government cloud

### How it will stay current

The same as the commercial connector: a weekly full export and daily deltas.

## What your customers will need

- An app registration in Azure Government with the same permissions as the commercial connector. Commercial and government tokens are not interchangeable.

## Until it's available

Build against the [Sandbox](/connectors/sandbox) connector, which produces findings of every type. Every connector shares one data model, so the code you write keeps working when this connector ships.
