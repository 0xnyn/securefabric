## What SecureFabric will sync

| | |
|---|---|
| Resources | `HOST` |
| Findings | `HOST` |

From Microsoft Defender:

- Software vulnerabilities by machine (full export)
- Software vulnerability changes by machine (delta export)
- Machines

### How it will stay current

A full export weekly and a delta export daily. Microsoft refreshes this data every 6 hours, so a change can take up to 6 hours to appear.

## What your customers will need

- A Microsoft Entra administrator to consent to the app, with the Microsoft Defender for Endpoint API permissions `Vulnerability.Read.All`, `Machine.Read.All` and `Software.Read.All`.
- Microsoft Defender for Endpoint Plan 2, which includes core vulnerability data, or Defender Vulnerability Management.

## Good to know
