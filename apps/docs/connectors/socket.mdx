## What SecureFabric will sync

| | |
|---|---|
| Resources | `REPOSITORY`, `DEPENDENCY` |
| Findings | `DEPENDENCY` |

From Socket:

- Organization alerts
- Organization repositories

### How it will stay current

Each sync reads all alerts. Socket meters API use with a quota per hour, which sets how often syncs can run.

## What your customers will need

- A Socket organization API token with the scopes for alerts and repositories. The free plan includes API access.

## Good to know

- Socket's alerts API is in beta.

## Until it's available

Build against the [Sandbox](/connectors/sandbox) connector, which produces findings of every type. Every connector shares one data model, so the code you write keeps working when this connector ships.
