### How it will stay current

Each sync reads vulnerabilities updated since the last sync. CrowdStrike removes expired vulnerabilities after 3 days, so syncs run at least daily.

## What your customers will need

- A CrowdStrike API client with the Vulnerabilities: Read and Hosts: Read scopes.
- The Falcon Spotlight or Exposure Management module, which CrowdStrike licenses separately.

## Until it's available

Build against the [Sandbox](/connectors/sandbox) connector, which produces findings of every type. Every connector shares one data model, so the code you write keeps working when this connector ships.
